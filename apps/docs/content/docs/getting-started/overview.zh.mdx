## 前提条件

开始之前，请确保你有：
- 一个 Flowmail 账户（[在此注册](https://flowmail.ai)）
- 一个 Gmail 或 Outlook 邮箱账户用于连接
- 组织管理员权限（如果加入已有团队）

## 第一步：创建你的组织

注册后，为你的团队创建一个组织。组织提供完整的数据隔离 — 每个团队的邮件和业务实体都是分开存储的。

## 第二步：连接邮箱

进入 **设置 → 邮箱连接**，点击 **连接 Gmail** 或 **连接 Outlook**。

Flowmail 使用 **OAuth 2.0** 进行认证 — 我们永远不会看到或存储你的邮箱密码。连接只请求所需的最小权限：
- 读取邮件消息和元数据
- 代你发送邮件（用于审批回复）

## 第三步：探索智能收件箱

连接完成后，Flowmail 开始处理你收到的邮件。智能收件箱按业务类型组织邮件：

| 分类 | 描述 |
|------|------|
| **审批** | 需要你决策的请求（通过/拒绝） |
| **汇报** | 进展更新、周报、状态摘要 |
| **问题** | 问题报告、bug 通知、升级处理 |
| **反馈** | 客户反馈、调查回复、评价 |

## 第四步：审核并执行

对于每封邮件，Flowmail 的 AI 会提取：
- **分类** — 这是什么类型的业务事项
- **关键字段** — 申请人、截止时间、金额、优先级等
- **建议操作** — 你接下来应该做什么

审核 AI 的建议并确认执行。每个决策都记录在实体的时间线中，提供完整的审计追溯。
