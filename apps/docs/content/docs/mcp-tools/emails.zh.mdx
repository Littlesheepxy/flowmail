邮件工具提供对已同步邮件线程和连接管理的访问能力。

## list_email_connections

列出组织内所有已连接的邮箱账户。

### 参数

无需参数。

---

## search_emails

按关键词、发件人或主题搜索邮件。返回匹配的邮件线程及其关联的实体。

### 参数

| 名称 | 类型 | 必填 | 描述 |
|------|------|------|------|
| `query` | `string` | 否 | 在主题和正文中搜索的关键词 |
| `sender` | `string` | 否 | 按发件人邮箱或姓名筛选 |
| `limit` | `number` | 否 | 最大返回数量（默认：10） |

`entity` 字段将邮件关联到其结构化业务实体（如果已被提取）。
