---
title: 时间线工具
description: 用于管理实体时间线的 MCP 工具 — 添加事件、计算 AI 语义差异、预测风险。
---

时间线工具让 Agent 能够追踪业务实体的历史，并利用 AI 进行分析。

## add_timeline_event

向实体的时间线添加一条手动事件。用于记录里程碑、备注、决策或任何重要时刻。

### 参数

| 名称 | 类型 | 必填 | 描述 |
|------|------|------|------|
| `entityId` | `string` | 是 | 要添加事件的实体 ID |
| `type` | `string` | 是 | 事件类型：`"note"` / `"milestone"` / `"action_taken"` / `"status_changed"` / `"ai_summary"` / `"email_sent"` |
| `content` | `string` | 是 | 事件内容描述 |
| `metadata` | `object` | 否 | 可选的结构化元数据 |

---

## get_entity_timeline

获取业务实体的完整时间线事件，按时间顺序排列。

### 参数

| 名称 | 类型 | 必填 | 描述 |
|------|------|------|------|
| `entityId` | `string` | 是 | 实体 ID |
| `types` | `string[]` | 否 | 按事件类型筛选 |

---

## get_timeline_diff

获取实体时间线两个时间点之间的 AI 语义差异分析。用于理解一段时间内发生了什么变化。

### 参数

| 名称 | 类型 | 必填 | 描述 |
|------|------|------|------|
| `entityId` | `string` | 是 | 实体 ID |
| `fromEventId` | `string` | 否 | 起始事件 ID（默认为第一个事件） |
| `toEventId` | `string` | 否 | 结束事件 ID（默认为最新事件） |

**注意：** AI 分析需要配置 AI 模型密钥。未配置时，工具返回所选范围内的原始事件。

---

## predict_entity_risk

AI 驱动的业务实体风险预测。分析时间线历史、抽取字段和当前状态来评估风险。

### 参数

| 名称 | 类型 | 必填 | 描述 |
|------|------|------|------|
| `entityId` | `string` | 是 | 要分析的实体 ID |

### 返回值示例

```json
{
  "riskLevel": "medium",
  "riskFactors": [
    "审批截止日期还有 2 天",
    "审批人已 5 天未回复"
  ],
  "predictedOutcome": "如不干预，可能错过截止日期",
  "suggestedActions": [
    "向审批人发送提醒",
    "升级到审批人的上级"
  ],
  "confidence": 0.78
}
```

**注意：** 需要配置 AI 模型密钥才能进行预测。未配置时返回 `{ "riskLevel": "unknown" }`。
