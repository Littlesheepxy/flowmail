title: 实体工具
description: 用于列出、查看和更新结构化业务实体的 MCP 工具。
---

实体（Entity）是 Flowmail 的核心数据模型 — 从邮件中提取的结构化业务事项（审批、汇报、问题、反馈）。

## list_entities

列出组织的结构化业务实体。

### 参数

| 名称 | 类型 | 必填 | 描述 |
|------|------|------|------|
| `type` | `"APPROVAL" \| "REPORT" \| "ISSUE" \| "FEEDBACK"` | 否 | 按实体类型筛选 |
| `status` | `string` | 否 | 按状态筛选（如 `"pending"`、`"approved"`） |
| `limit` | `number` | 否 | 最大返回数量（默认：20） |

### 示例

```json
{
  "tool": "list_entities",
  "arguments": {
    "type": "APPROVAL",
    "status": "pending",
    "limit": 10
  }
}
```

### 返回值

返回实体数组，包含负责人信息，按最近更新时间排序。

---

## get_entity

获取业务实体的完整详情，包括时间线事件和关联的邮件线程。

### 参数

| 名称 | 类型 | 必填 | 描述 |
|------|------|------|------|
| `entityId` | `string` | 是 | 实体 ID |

### 返回值

返回完整的实体信息，包括：
- 实体元数据（标题、类型、状态、抽取字段）
- 负责人信息
- 关联的邮件线程（主题、发件人、摘要、日期）
- 完整的时间线事件及操作者信息

---

## update_entity_status

更新业务实体的状态。自动创建一条记录变更的时间线事件。

### 参数

| 名称 | 类型 | 必填 | 描述 |
|------|------|------|------|
| `entityId` | `string` | 是 | 实体 ID |
| `status` | `string` | 是 | 新状态值 |
| `reason` | `string` | 否 | 状态变更原因 |
