欢迎来到 Flowmail 文档。在这里你可以找到开始使用和充分利用平台所需的一切。

## 什么是 Flowmail？

Flowmail 是一个 **AI 原生业务执行平台**，位于你的邮箱收件箱之上。它自动分类收到的邮件、提取结构化业务数据，并让你在一个界面中完成所有操作。

## 核心概念

- **智能收件箱** — 按业务类型组织邮件：审批、汇报、问题等
- **业务实体** — 从邮件中提取的结构化业务事项，包含完整时间线追踪
- **操作面板** — 一键操作：审批、拒绝、更新状态、分配、跟进
- **AI 管线** — 自动分类和数据抽取，人在回路确认

## 快速开始

1. [创建账户](/docs/getting-started/overview)并设置你的组织
2. 通过安全的 OAuth 连接邮箱（Gmail 或 Outlook）
3. 开始处理邮件 — Flowmail 的 AI 会自动分类和提取数据
4. 审核 AI 的建议并执行操作

## 场景

### 审批工作流
将审批请求邮件转化为可追踪的事项。查看申请人、内容和截止时间，一键审批或拒绝。

### 汇报跟踪
自动从团队汇报中提取进展更新。追踪状态变化，在检测到风险时收到提醒。

## 架构

Flowmail 提供两个 API 层以实现最大灵活性：

- **oRPC** — 为 Web UI 提供的类型安全 RPC（控制台使用）
- **MCP Server** — 为 AI Agent 集成提供的 Model Context Protocol（Claude、GPT、Cursor 等 Agent 使用）

两个层共享相同的核心业务逻辑，确保所有接口的一致性。
