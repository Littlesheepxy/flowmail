# 网易 163 邮箱接入

## 接入方式

IMAP/SMTP（授权码模式），无 OAuth。

## 服务器配置

| 协议 | 服务器 | 端口 | 加密 |
|------|--------|------|------|
| IMAP（收信） | imap.163.com | 993 | SSL |
| SMTP（发信） | smtp.163.com | 465 | SSL |

Flowmail 前端已内置 `163.com` 自动识别，用户输入邮箱后自动填充服务器地址。

## 用户操作流程

### 第一步：开启 IMAP 服务

1. 浏览器登录 [mail.163.com](https://mail.163.com/)
2. 点击顶部 **设置** → 左侧菜单选择 **POP3/SMTP/IMAP**
3. 将 **IMAP/SMTP 服务** 开关打开

### 第二步：获取授权码

1. 在同一设置页面，找到「客户端授权密码」区域
2. 点击 **开启** 或 **新增授权密码**
3. 按提示用绑定手机发送短信完成安全验证
4. 验证通过后系统生成 **16 位授权码**
5. **立即复制保存**，授权码仅显示一次

### 第三步：在 Flowmail 中连接

1. 进入 Flowmail → 设置 → 邮箱连接
2. 点击「连接个人邮箱」
3. 填写：
   - **邮箱地址**：your@163.com
   - **应用专用密码**：粘贴第二步获取的授权码
   - IMAP 服务器和端口会自动填充
4. 选择「首次同步数量」（默认 500 封）
5. 点击「测试并连接」

## 注意事项

- 授权码 ≠ 登录密码，是专为第三方客户端生成的独立密码
- 建议为 Flowmail 单独生成一个授权码，便于管理
- 一个手机号每天最多发送 3 次验证短信
- 可在 163 设置页面随时禁用或重新生成授权码
- 126.com 邮箱流程完全一致，IMAP 服务器为 `imap.126.com`
